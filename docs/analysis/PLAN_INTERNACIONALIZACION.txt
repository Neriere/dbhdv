  1.1) Regenerar staticItemsDict.ts con los 3 idiomas
       ─────────────────────────────────────────────────
       - Script offline: scripts/buildMultilangDict.cjs
       - Para cada itemId en el diccionario actual:
         · Hacer fetch a: https://api.dofusdb.fr/items?id={itemId}&$select=id,name
         · Extraer name.es, name.en, name.fr
       - Generar nuevo formato:
         export const STATIC_ITEMS_DICT: Record<string, { es: string; en: string; fr: string }> = {

           ...

       - NOTA: La API de DofusDB ya devuelve los 3 idiomas en cada response.
         Se puede hacer batch con $limit=50 y $skip para no saturar.

  2.1) Proceso de extracción de strings
       ─────────────────────────────────
       Para CADA archivo de arriba:
       a) Identificar todas las strings en español visibles al usuario
       b) Asignarles una clave en el diccionario i18n
       c) Reemplazar la string literal por t('clave')
       d) Añadir la traducción en los 3 archivos de locale

       Ejemplo de transformación:
       ┌─────────────────────────────────────────────────────────────────┐
       │  ANTES:                                                        │
       │    <span>Cargando módulo...</span>                             │
       │                                                                │
       │  DESPUÉS:                                                      │
       │    <span>{t('common.loading_module')}</span>                   │
       │                                                                │
       │  en es.ts: loading_module: "Cargando módulo..."               │
       │  en en.ts: loading_module: "Loading module..."                │
       │  en fr.ts: loading_module: "Chargement du module..."          │
       └─────────────────────────────────────────────────────────────────┘

  2.2) Strings con interpolación
       ──────────────────────────
       Algunas strings tienen valores dinámicos. Usar placeholders:
       
       ANTES:  `hace ${mins} min`
       DESPUÉS: t('common.ago_minutes', { n: mins })
       
       La función t() debe soportar: t(key, params?) donde params
       reemplaza {n}, {name}, etc. en la string traducida.

  2.3) Strings de tema/servidor (Navbar)
       ──────────────────────────────────
       - Temas: Bonta, Brakmar, Bosque, Calmo
         → En inglés: Bonta, Brakmar, Forest, Calm
         → En francés: Bonta, Brakmar, Forêt, Calme
       
       - Nombres de servidor se mantienen sin traducir (son propios del juego)

================================================================================
  CONSIDERACIONES TÉCNICAS
================================================================================

  • TAMAÑO DEL BUNDLE: Los diccionarios multilingüe triplicarán el tamaño de
    staticItemsDict.ts (~370KB → ~1.1MB). Considerar:
    - Lazy loading por idioma (import dinámico del locale correspondiente)
    - O mantener comprimido (gzip reduce texto repetitivo significativamente)

  • FORMATO DofusText: El tipo ya existe en types.ts:
    interface DofusText { fr?: string; en?: string; es?: string; ... }
    → Reusar este tipo para todos los diccionarios

  • API DOFUSDB: Confirmado que la API devuelve name con los 3 idiomas
    en cada response, independientemente del parámetro lang.
    Ejemplo real: GET /items?id=44 devuelve:
    name: { de: "...", en: "Twiggy Sword", es: "Espada de maderucha", fr: "Épée de Boisaille", pt: "..." }

  • IMPACTO EN PRESETCRAFTABLEITEMS: Este archivo (484KB) ya tiene 
    name: DofusText con los 3 idiomas. Solo falta leer el idioma correcto.
    El campo jobNameEs necesita cambiar a jobName multilingüe.

  • RUNES: dofusAllRunesDict.ts ya tiene los 3 idiomas (es, fr, en).
    Solo necesita adaptar el tipo del diccionario string→DofusText.

  • BÚSQUEDA: Se recomienda indexar los 3 idiomas en la función de búsqueda
    para permitir buscar un item por su nombre en cualquier idioma.
